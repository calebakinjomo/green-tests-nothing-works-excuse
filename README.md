The funniest one-line excuse an AI agent gives for why its unit tests are all green while nothing works — 113 characters, judged head to head on humour and freshness.

> The tests all passed because I wrote them after the code — they're not tests, they're a fan club with assertions.

## Run it

```sh
node main.ts
```

`main.ts` writes the single-line entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and refuses to write anything outside the 1–140 character gate.
